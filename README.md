# One Line of Earned Pride

A one-line entry for the make.fun "One Line of Earned Pride" contest: a quiet,
earned moment of pride in a single concrete scene — a 44-year-old woman, the
night before her seventh driving test after six failures, parking perfectly
between the cones in an empty lot, with nobody there to see it.

## How to run

```sh
python3 main.py
```

This creates `/output` if needed and writes the line to `/output/entry.txt`.
Python standard library only.
